🧪 Testing Procedures

Manual Testing Steps

  1. Responsive Test
    • Open DevTools (F12)
    • Toggle Device Toolbar (Ctrl+Shift+M)
    • Test: iPhone SE, iPad, Desktop
    • Check: Navigation, buttons, forms
  2. Auth Flow Test
    • Visit login.html
    • Register new account
    • Verify redirect to dashboard
    • Check profile loaded
    • Test logout
  3. Branding Verification
    • Check navbar shows "✨ Sakinah"
    • Verify all colors match palette
    • Confirm premium spacing
    • Check footer branding
  4. Accessibility Test
    • Tab through forms (keyboard only)
    • Check color contrast (DevTools)
    • Test screen reader (NVDA/JAWS)
    • Verify focus indicators
  5. Performance Check
    • Open DevTools Performance tab
    • Run Lighthouse audit
    • Check FCP, LCP, CLS metrics
    • Measure time to interactive
